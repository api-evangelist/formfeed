# Formfeed documentation

> Formfeed renders PDFs and images from HTML templates written in Jinja2, Liquid or Handlebars and
> JSON data, and fills Word and PowerPoint files that carry the same tags. Hosted in the EU
> (Frankfurt), priced in EUR. It has a browser editor, a CLI for templates as files, SDKs for
> TypeScript and Python, and an MCP server for AI agents.

The API reference is left out of both files: it is generated from the OpenAPI document, and that
document is the better machine-readable source: https://api-eu.formfeed.dev/v1/openapi.json

## Start here

- [Formfeed documentation](https://docs.formfeed.dev/): Formfeed turns an HTML template and a JSON payload into a PDF or an image. One REST call, three template languages, EU hosting.

## Errors

- [invalid_request](https://docs.formfeed.dev/errors/invalid-request): HTTP 400 Invalid request. The request could not be understood: the body is not valid JSON, a field has the wrong type or value, or a combination of fields is not allowed.
- [unauthorized](https://docs.formfeed.dev/errors/unauthorized): HTTP 401 Unauthorized. The request carries no API key, or the key is not valid.
- [forbidden](https://docs.formfeed.dev/errors/forbidden): HTTP 403 Forbidden. The key is valid but lacks the scope this endpoint needs, or the plan does not include the feature.
- [not_found](https://docs.formfeed.dev/errors/not-found): HTTP 404 Not found. The render, job, webhook endpoint or path does not exist in this workspace.
- [template_not_found](https://docs.formfeed.dev/errors/template-not-found): HTTP 404 Template not found. No template with this slug or id has a published version in the workspace of the key.
- [conflict](https://docs.formfeed.dev/errors/conflict): HTTP 409 Conflict. The request conflicts with the current state: a slug is taken, or the template changed since the version you based your change on.
- [quota_exceeded](https://docs.formfeed.dev/errors/quota-exceeded): HTTP 402 Quota exceeded. The units of the current period are used up and this plan cannot continue with overage.
- [template_syntax_error](https://docs.formfeed.dev/errors/template-syntax): HTTP 422 Template syntax error. The template could not be compiled: a tag is not closed, a bracket is missing, or the syntax belongs to another template language.
- [template_runtime_error](https://docs.formfeed.dev/errors/template-runtime): HTTP 422 Template runtime error. The template compiled, but failed while it ran with your data.
- [data_validation_error](https://docs.formfeed.dev/errors/data-validation): HTTP 422 Data validation failed. The data does not match the template's data schema.
- [navigation_failed](https://docs.formfeed.dev/errors/navigation-failed): HTTP 422 Navigation failed. A `url` render could not load the page.
- [page_limit_exceeded](https://docs.formfeed.dev/errors/page-limit): HTTP 422 Page limit exceeded. The PDF has more pages than the plan allows for one document.
- [output_too_large](https://docs.formfeed.dev/errors/output-too-large): HTTP 422 Output too large. The rendered file, or the HTML that produces it, is larger than the limit.
- [rate_limited](https://docs.formfeed.dev/errors/rate-limited): HTTP 429 Rate limited. The workspace sent more requests that start work than the plan allows per second.
- [worker_exhausted](https://docs.formfeed.dev/errors/worker-exhausted): HTTP 500 Render retries exhausted. The render failed for a reason on Formfeed's side and the retries did not help, or an unexpected error occurred.
- [region_unavailable](https://docs.formfeed.dev/errors/region-unavailable): HTTP 503 Region unavailable. The requested region cannot take the render right now, or does not exist yet.
- [render_timeout](https://docs.formfeed.dev/errors/render-timeout): HTTP 504 Render timed out. The render took longer than allowed: the template step is limited to 5 seconds, printing in Chromium to 30 seconds.
- [not_implemented](https://docs.formfeed.dev/errors/not-implemented): HTTP 501 Not implemented yet. The endpoint or option is part of the API contract but not available yet.
- [source_not_found](https://docs.formfeed.dev/errors/source-not-found): HTTP 422 Source not found. A PDF tool or a `post.merge_after` entry names a render whose output cannot be found.
- [source_invalid](https://docs.formfeed.dev/errors/source-invalid): HTTP 422 Source cannot be processed. A PDF tool or a `post.merge_after` entry names a render that is not a finished PDF.
- [source_encrypted](https://docs.formfeed.dev/errors/source-encrypted): HTTP 422 Source is encrypted. The PDF is password-protected, so it can no longer be merged or watermarked.
- [tool_failed](https://docs.formfeed.dev/errors/tool-failed): HTTP 500 PDF tool failed. Merging, protecting or watermarking failed while processing the PDF.
- [file_too_large](https://docs.formfeed.dev/errors/file-too-large): HTTP 413 File too large. The file you uploaded is over the limit: 10 MB for the workspace library, 20 MB for an office document to convert or a Word or PowerPoint template.
- [schema_breaking_change](https://docs.formfeed.dev/errors/schema-breaking-change): HTTP 409 Schema change breaks callers. Publishing, moving a channel, promoting or rolling back would put a version live whose stored data schema breaks callers of the current one.
- [channel_not_found](https://docs.formfeed.dev/errors/channel-not-found): HTTP 404 Channel not found. The request names a release channel the template does not have.
- [channel_name_invalid](https://docs.formfeed.dev/errors/channel-name-invalid): HTTP 422 Invalid channel name. A release channel name is malformed or reserved.
- [channel_in_use](https://docs.formfeed.dev/errors/channel-in-use): HTTP 409 Channel in use. A release channel cannot be deleted because renders of the last hour used it.
- [render_input_expired](https://docs.formfeed.dev/errors/render-input-expired): HTTP 410 Render request not kept. The request of a render was not stored, or its retention period ended.
- [listen_session_limit](https://docs.formfeed.dev/errors/listen-session-limit): HTTP 409 Too many listen sessions. Three formfeed listen sessions are already running in the workspace.
- [listen_session_ended](https://docs.formfeed.dev/errors/listen-session-ended): HTTP 410 Listen session ended. A delivery, a resend or a connection named a formfeed listen session that is gone.
- [last_workspace](https://docs.formfeed.dev/errors/last-workspace): HTTP 409 Last workspace. The workspace cannot be deleted because the organisation has no other one.
- [file_type_unsupported](https://docs.formfeed.dev/errors/file-type-unsupported): HTTP 415 File type not supported. The uploaded file is not an office document Formfeed converts, or it contains macros.
- [office_document_invalid](https://docs.formfeed.dev/errors/office-document-invalid): HTTP 422 Office document invalid. The file looks like an office document but its container is damaged or fails a safety check.
- [office_document_too_large](https://docs.formfeed.dev/errors/office-document-too-large): HTTP 422 Office document too large. The document unpacks to more than Formfeed processes.
- [office_conversion_failed](https://docs.formfeed.dev/errors/office-conversion-failed): HTTP 422 Office conversion failed. LibreOffice could not convert the document, twice in a row.
- [office_unavailable](https://docs.formfeed.dev/errors/office-unavailable): HTTP 503 Office conversion unavailable. The converter is busy or not reachable right now.
- [test_output_unavailable](https://docs.formfeed.dev/errors/test-output-unavailable): HTTP 403 Output not available for test renders. On the Free plan, test renders of Word and PowerPoint templates produce the marked PDF only.
- [unsupported_in_office](https://docs.formfeed.dev/errors/unsupported-in-office): HTTP 422 Not supported in office templates. A Word or PowerPoint template uses a tag that office templates cannot run, such as an include.
- [storage_not_configured](https://docs.formfeed.dev/errors/storage-not-configured): HTTP 409 Storage not configured. The request names an object in the workspace's own bucket, or tests or redelivers copies, but the workspace has no storage connection.
- [storage_test_failed](https://docs.formfeed.dev/errors/storage-test-failed): HTTP 422 Storage test failed. Formfeed could not write the test object to the bucket, so the storage connection was not saved.
